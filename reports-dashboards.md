# Reports & Dashboards

## What is a Report?

A Report in Salesforce is a list of records that meet specific criteria.

Reports help users:
- Analyze data
- Track performance
- Identify trends
- Make business decisions

Example:
A report showing all open support cases.

---

## Types of Reports

### 1. Tabular Report

- Simplest report format
- Displays records in rows
- No grouping

Example:
List of all Accounts.

### 2. Summary Report

- Records grouped by rows
- Shows subtotals

Example:
Cases grouped by Status.

### 3. Matrix Report

- Groups records by rows and columns
- Useful for comparisons

Example:
Cases grouped by Status and Priority.

### 4. Joined Report

- Combines multiple report types
- Displays related information together

Example:
Accounts and Opportunities in one report.

---

## What is a Dashboard?

A Dashboard is a visual representation of report data.

Dashboards help users:
- Monitor KPIs
- Track business performance
- View data visually

---

## Dashboard Components

Common dashboard components:

- Chart
- Gauge
- Metric
- Table
- Funnel

---

## Report vs Dashboard

| Report | Dashboard |
|----------|-----------|
| Detailed data | Visual data |
| Tabular format | Graphical format |
| Used for analysis | Used for monitoring |
| Can exist alone | Uses report data |

---

## Summary

Reports store and analyze data, while Dashboards visually display report information for quick decision-making.
