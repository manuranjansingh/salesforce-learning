# Data Management

## What is Data Management?

Data Management in Salesforce is the process of importing, exporting, updating, cleaning, and maintaining data.

Good data management helps maintain data accuracy and quality.

---

## Data Import Wizard

The Data Import Wizard is a Salesforce tool used to import records.

Features:
- Easy to use
- Supports standard and custom objects
- Can update existing records

Example:
Importing Leads from an Excel file.

---

## Data Loader

Data Loader is a client application used for large data operations.

Functions:
- Insert
- Update
- Upsert
- Export
- Delete

Best used when handling thousands of records.

---

## Export Data

Salesforce allows scheduled or manual data exports.

Benefits:
- Backup data
- Data migration
- Reporting requirements

---

## Duplicate Management

Duplicate Management helps prevent duplicate records.

Tools:
- Matching Rules
- Duplicate Rules

Example:
Prevent creation of duplicate Contacts.

---

## Recycle Bin

Deleted records are stored temporarily in the Recycle Bin.

Users can restore records if needed.

---

## Summary

Salesforce provides multiple tools such as Data Import Wizard and Data Loader to efficiently manage, clean, and maintain organizational data.
